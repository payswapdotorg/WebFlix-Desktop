## 7. Contract & ownership proposals for TL2's freeze

- **Module roots (existing, already declared in architecture-policy.yaml:49-51):** keep `packages/desktop` (roots `packages/desktop/src`) as the Electron host module; promote to `managed: true` with owner `worker-1/desktop-shell`, public entrypoints: `src/preload/index.ts` (bridge), `packages/shared/src/channels.ts` (IPC vocabulary, co-owned with shared), `scripts/desktop-product-identity.mjs` (identity — TL2-owned values, worker-owned mechanism).
- **New module roots per architecture-lock §4** (`webflix-contracts`, `webflix-domain`, `webflix-application`, `catalog`, `connectors`, `playback`, `local-library`, …): introduce as TL2 locks them; desktop must import them only via their public entrypoints; desktop must **not** be imported by any of them (inward dependency direction, lock §3).
- **Public entrypoints to freeze first (Phase 1 blockers):** (1) product identity table (flavor → appId/productName/AUMID/scheme/data-root/updater-origin); (2) window/preload bridge surface (`window.zcode` — versioned, additive-only changes); (3) `PlatformChannels` registry (versioned; renames forbidden, additions via TL2); (4) local-media preview scheme + path-authorization contract; (5) renderer navigation/permission policy (add explicit permission handlers — currently absent).
- **Layer rules:** preload/main = platform adapters only; no WebFlix domain logic in `packages/desktop/src/main`; UI shell (`packages/ui`) presentation-only, platform ops via `IPlatformService` (`packages/shared/src/platform.ts`) as AGENTS.md already mandates.
- **Ownership split of this audit's flag list:** cookie-import + shared-partition decision spans Worker 3 (provider sessions) and me (host) — propose: I own partition mechanics & isolation tests; Worker 3 owns per-provider session/credential policy; TL2 arbitrates the shared decision. E2E runner + CI scaffolding: propose Worker 1 builds it in Lane D1 with TL2 owning workflow files (worker-protocol "shared-file owners").
